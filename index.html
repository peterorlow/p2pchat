SECURE LINK
peer-to-peer · no server

Messages travel straight between two devices, encrypted end-to-end. Nothing is stored or relayed by a server.

How the connection works
  1. One phone taps Start and generates a connection code.
  2. Share that code with the other phone — QR, AirDrop, text, in person.
  3. The other phone taps Join, enters the code, and generates a reply code.
  4. Send the reply code back. The two phones link up directly.
  5. Compare the safety number out loud once to confirm no one tampered with the codes.
